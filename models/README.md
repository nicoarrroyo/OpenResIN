# Models Directory
This is an output data folder, meaning you don't need to put anything in here yourself. Any models trained with the `openresin-train` command will be automatically saved here. Then, when the model is deployed with the `openresin-predict` command, it will be searched for here as well. Models will be saved as TensorFlow Keras models (e.g. `ndwi model epochs-150.keras`). That filename is how `openresin-predict` finds the model, so if you train with `--epochs 50` you have to deploy with `--model-epochs 50`. The same goes for `--model-type`.

Models are not tracked by git, so this directory arrives empty on a fresh clone. You will need to train a model (or be given one) before `openresin-predict` has anything to load. Both scripts resolve this location through `MODELS_DIR` in `src/openresin/config.py`; if you need to move it, change it there rather than in the scripts.
